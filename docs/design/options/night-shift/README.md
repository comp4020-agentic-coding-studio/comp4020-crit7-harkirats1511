# Night Shift

Grid-first, dark, instrument-like: the page is the Mon-Fri board; a right drawer (bottom sheet on mobile) holds options.

**Type:** system grotesque + system mono, tabular numerals for times.

**Palette (dark):** bg #16140f, surface #1e1b15, text #efe9dc (14.2:1 on surface), muted #c9c0ac (8.2:1; 5.2:1 on class fills), gold #e3b04b (9.3:1 on bg, reserved for today/now/yours), clash #ff9a8b (9.0:1 on bg; always with hatch, icon and the word "Clash"). Light: text #211d14 (15.8:1), gold #855900 (5.3:1), clash #a8241b (6.2:1).

**Motion:** 160-220ms, cubic-bezier(.32,.72,0,1): blocks rise in, ghosts fade, drawer slides, toast slides. Off under reduced motion. Deviation: the desktop board's margin eases when the drawer opens.
