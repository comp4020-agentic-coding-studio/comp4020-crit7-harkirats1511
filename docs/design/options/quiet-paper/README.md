# Quiet Paper ("Margin")

One thing at a time: 680px column on flat paper, hairline rules, small-caps labels, serif headline and numerals. The week is a readable time grid (960px on desktop, one day at a time on mobile).

**Type:** Iowan Old Style / Palatino / Georgia for headline and numerals; system-ui for the rest.

**Palette (measured):** paper #F5F0E4; ink #1E1B16 15.1:1; secondary #5A5347 6.7:1; ink-green #1F5A43 7.1:1 (button text 7.6:1); clash brick #A1341F 6.1:1 (5.3:1 on its tint); gold #A67810 only for the now line and today marker (3.5:1, non-text).

**Motion:** 200ms fade/slide, 220ms tick, transform/opacity only, off for reduced-motion.

**Engineering:** live seats and clash checks, real undo, recordings/convenor lookup, real .ics with recurrence.
