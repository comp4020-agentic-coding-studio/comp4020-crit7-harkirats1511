# Daybook (friendly, day-by-day)

**Personality:** a warm morning greeting, one day at a time. Sand page, oat surfaces, 14px radius, hairlines, no shadows. One deep-teal accent marks the active state; the problem is the only red.

**Type:** UI: DM Sans / Nunito Sans (not loaded), then the system stack. Greeting and headings: Fraunces (not loaded), then Iowan/Palatino/Georgia.

**Palette (measured):** ink #22251F on oat #FAF6EC 14.4:1; muted #55503F 7.5:1; white on teal #0E4F4F 9.3:1; clash #A32A1B 6.7:1 on oat, 5.6:1 on its tint. Courses: HCI #35557A, Agentic #6E4E00, Documents #74385A, Finance #416024, each 5.7-7.9:1 on its tint. Clash also carries a triangle icon and the word.

**Motion:** chip pill slide, staggered block rise, ghost fade, sheet spring, toast slide plus check draw; 200-350ms, transform/opacity. All off under `prefers-reduced-motion`.
